# Movie Recommendation Engine

A Java-based movie recommendation application that suggests films based on shared attributes such as genres and directors.

## Features

- Search through a collection of over 1,000 movies by title
- Compare movie attributes to identify similar films
- Generate recommendations based on shared characteristics
- Organize movie information using object-oriented Java classes
